### 📌 ObjectId Data Type in MongoDB

**ObjectId** is a special data type used in MongoDB to create **unique IDs** for each document.

---

## 🔹 Simple Definition

👉 **ObjectId = Unique identifier (ID) for each document**

Example:

```js
{
  _id: ObjectId("6616f5a2c8f1a2b3d4e5f678"),
  name: "Prashant",
  age: 22
}
```

---

## 🔹 Structure of ObjectId (12 Bytes)

An ObjectId is made of **12 bytes**, divided into 3 parts:

1. **4 bytes → Timestamp**
   👉 When the document was created

2. **5 bytes → Random value (machine + process)**
   👉 Makes it unique across systems

3. **3 bytes → Counter**
   👉 Auto-incrementing value

---

## 🔹 Example Breakdown

ObjectId:

```
6616f5a2c8f1a2b3d4e5f678
```

| Part       | Meaning   |
| ---------- | --------- |
| 6616f5a2   | Timestamp |
| c8f1a2b3d4 | Random    |
| e5f678     | Counter   |

---

## 🔹 Key Features

✅ Automatically generated by MongoDB
✅ Always unique
✅ Sorted by creation time
✅ Used as primary key (`_id`)

---

## 🔹 Why ObjectId is Important?

* No need to manually create IDs
* Works in distributed systems
* Faster and scalable
* Helps track creation time

---

## 🔹 How to Create ObjectId Manually

```js
ObjectId()
```

Or in query:

```js
db.users.find({ _id: ObjectId("6616f5a2c8f1a2b3d4e5f678") })
```

---

## 🔹 Important Tip (Very Important 🔥)

When searching by `_id`, you must use **ObjectId**, not string:

❌ Wrong:

```js
db.users.find({ _id: "6616f5a2c8f1a2b3d4e5f678" })
```

✅ Correct:

```js
db.users.find({ _id: ObjectId("6616f5a2c8f1a2b3d4e5f678") })
```
